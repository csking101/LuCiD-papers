Path-Finding Preference Game

Full RLHF pipeline in a grid world — you are the human annotator. Pre-train an agent, rate trajectory pairs, train a Bradley-Terry reward model, and PPO fine-tune with KL penalty. Covers concepts from papers 1706.03741, 1707.06347, and 2009.01325. Terminal-based UI with Rich. 201 tests. ~2 min runtime.

KL Divergence: Implication on LLM Outputs

Load Qwen2.5-1.5B base + instruct side-by-side and see how KL divergence manifests in real token distributions. Per-token KL analysis, category comparison (safety vs style vs helpfulness), and KL-constrained generation at different beta values. Covers concepts from papers 1707.06347, 1706.03741, and 2009.01325. 98 tests. Requires 8GB VRAM.

03

Solve a Rubik's Cube with RL

Train a neural network to solve a 2×2 Pocket Cube using PPO with curriculum learning. Start at depth-1 scrambles, advance when solve rate ≥80%, progress through depths 1–7. Covers PPO from 1707.06347 in a pure RL setting. 162 tests. GPU optional. ~2.5 min training time.

Done Alignment
04

System Prompt Steering

Measure how system prompts steer token distributions using KL divergence. Load Qwen2.5-1.5B-Instruct and compare first-token probabilities under 7 system prompts × 7 user prompts. Formatting/persona prompts are 36× stronger steerers than safety prompts. Covers concepts from 2203.02155 (InstructGPT). 128 tests. Requires ~3GB VRAM.

Qwen2.5-1.5B Interactive CLI 128 Tests
Done Alignment
05

Intent Hooks

Use PyTorch forward hooks to intercept hidden states and train linear probes to classify user intent (benign vs harmful). Build a guardrail that blocks harmful prompts before generation. 100% probe accuracy at layer 13/28, 100% jailbreak catch rate. Covers concepts from 2203.02155 (InstructGPT). 174 tests. Requires ~3GB VRAM.
